# Troi Manimtim Static Portfolio

This is the PHP-free version of the portfolio. It uses HTML, Bootstrap 5, Tailwind CSS browser CDN, Bootstrap Icons, and vanilla JavaScript.

## Edit content

Start with `assets/js/data.js`. It contains skills, experience, education, credentials, and projects.

Personal details are in `index.html` and `cv.html`.

## Add profile photo

Put your image in `assets/images/profile.jpg`, then replace the profile placeholder in `index.html` with an `<img>` element.

## Add CV

Replace `documents/CV.pdf` with your real PDF.

## Project links

Use real URLs only. Leave `demoUrl` and `sourceUrl` empty when you do not have those links.

## Run

Open `index.html` directly or use VS Code Live Server.

## Hosting

This is static and can be hosted on GitHub Pages, Netlify, Vercel, or normal static hosting.

The Tailwind browser CDN is chosen for easy editing. For a highly optimized production build, Tailwind can later be installed as a build dependency.
